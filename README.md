# Urna Live — Lula 13 × Flávio Bolsonaro 22

Protótipo interativo de entretenimento para transmissões. Votos fictícios, sem relação com eleições reais.

## Publicar

Adicione `index.html`, `lula.png` e `flavio.png` na raiz deste repositório, na branch `main`.

Depois acesse **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.

URL esperada após ativar o GitHub Pages: https://llXxizixXll.github.io/urna-live/

A conexão TikFinity ainda não está implementada nesta versão.
